Simple 5th-grade style explanation
  1. Assalamualaikum, yeh WAQueen QA checklist page hai. Iska kaam daily testing ko simple banana hai.
  2. Sab se pehle tester apna naam aur app ka staging URL likhega. Is page par koi password, API key, ya license key nahi likhni.
  3. Upar progress summary hai: total tests, pass, fail, skip, aur percentage. Jaise school test mein marks count hotay hain, yahan QA progress count hoti hai.
  4. Har feature ka apna card hai. Card mein title, link, steps, aur expected result diya hua hai.
  5. Tester link open karega, steps follow karega, phir result choose karega. Agar sab sahi ho to Pass. Agar expected result match na ho to Fail. Agar feature available nahi ya data missing ho to Skip.
  6. Fail par screenshot ya short video lazmi hai. Notes field mein bug ka clear reason likhna hai.
  7. Page refresh ke baad progress lose nahi hoti, kyun ke browser localStorage mein save hoti hai.
  8. End par Copy report button se summary clipboard mein aa jati hai. Download PDF button browser print dialog open karta hai, wahan Save as PDF choose karna hai.
  9. Final testing mein Login, Dashboard, WhatsApp connection, Customers, Inbox, Campaigns, AI, Knowledge Base, Billing, API, Webhooks, Mobile, aur Support sab cover honay chahiye.
